# James Raj's website

Static personal website at [jamesraj.me](https://jamesraj.me/) with a UCLA mirror.

Colors for the pages, scientific figures, videos, posters, and favicons are configured in [`theme/theme.json`](theme/theme.json). Palette swatches are separate from website roles, media roles, and per-figure assignments.

See [the theming guide](docs/THEMING.md) for examples, setup, previews, rebuilding, verification, and deployment. The current artwork is preserved until a full theme build is explicitly applied.
